# 絶妖星乱舞 P4 アシスタント｜DMU P4 Assistant

FF14 絶妖星乱舞（Dancing Mad (Ultimate)）P4 の補助ツールです。

https://miwi-jp.github.io/dmu_p4_assistant/

## 使い方

1. 暗記フェーズ：「1回目」「2回目」の画面で、付いたデバフ（真偽・水雷・早遅・加速度・ほのお／つなみ）を選びます。
2. 発動フェーズ：結果画面の①〜⑥に、それぞれの処理が順番に表示されます。②④⑤の真偽は、その場で選びます。

日本語と英語に対応しています（画面下で切り替え）。

---

A helper tool for FFXIV Dancing Mad (Ultimate) P4. Memorize your debuffs in two steps, then follow the resolve timeline ①–⑥. Available in Japanese and English.
